# Java Programming

## About
This repository contains my Java programming practice programs and assignments for logic building and problem-solving.

## How to Execute

**1. Compile the program:**
```cmd
javac program1.java
```

**2. Run the compiled program:**
```cmd
java program1
```

**Note:** To compile and run in one command (Java 11+):
```cmd
java program1.java
```
